# 🌿 Plantora

Plantora is an IoT-based Smart Plant Health Monitoring System built using ESP32, sensors, ThingSpeak, and a web dashboard.

## Features

- Real-time Temperature Monitoring
- Humidity Monitoring
- Soil Moisture Monitoring
- Light Intensity Monitoring
- Plant Health Analysis
- Health Score Generation
- Personalized Plant Care Recommendations
- Indoor and Outdoor Plant Support

## Technologies Used

- ESP32
- DHT Sensor
- Soil Moisture Sensor
- LDR Sensor
- HTML
- CSS
- JavaScript
- ThingSpeak

## Workflow

Sensors → ESP32 → ThingSpeak Cloud → Plantora Dashboard
